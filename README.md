# MimoPet - Checkout de Compras

Aplicação e-commerce desenvolvida em React para simulação de finalização de compra de produtos pet.

## 🚀 Tecnologias Utilizadas
- React + Vite
- React Router DOM
- React Hook Form + Zod
- CSS3 (Acessibilidade e Responsividade)
